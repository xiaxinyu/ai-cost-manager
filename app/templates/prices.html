Sync Microsoft catalog (REST)

Imports from the Microsoft unit-price REST API (prices.azure.com) — the same catalog that backs Azure OpenAI pricing (GPT-5.1 / GPT-5.2 tables on azure.microsoft.com). Legacy azure.microsoft.com/.../pricing/api JSON endpoints often return HTML now; this app does not scrape marketing HTML. Use GPT-5.1 + GPT-5.2 (Series…) with region eastus2 to match the East US 2 marketing tables, or East US 2 — GPT-4o + GPT-5.1…5.5 for the wider retail slice. Reference links live on the Price sources page.
